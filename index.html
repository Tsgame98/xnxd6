Mở Trên Bất Kỳ Máy Nào & Khôi Phục Tức Thì

Mọi thay đổi của bạn (tin nhắn AI, sổ tay, công việc, code, bảng vẽ, repo đã ghim) đều được lưu tự động trong trình duyệt này. Khi muốn chuyển sang máy tính hoặc điện thoại khác mà không cần đăng nhập, bạn có 3 cách cực nhanh:

Cách 1: Tạo Đường Link Chứa Toàn Bộ Dữ Liệu (URL Hash)

Khuyên dùng

Mã hóa toàn bộ ghi chú, công việc và lịch sử chat vào ngay sau dấu # của đường link. Mở link này ở bất kỳ thiết bị nào sẽ tự động nạp lại toàn bộ không gian làm việc!

Cách 2: Xuất File Dự Phòng (.JSON) hoặc Tải Trọn Bộ Web (.HTML)

Bạn có thể tải về file .html độc lập (chứa sẵn dữ liệu hiện tại của bạn bên trong) để mở trực tiếp trên mọi máy tính/điện thoại ngay cả khi không cần cài đặt gì.

🌐 Hướng Dẫn Chạy Địa Chỉ Web Riêng Miễn Phí Vĩnh Viễn (GitHub Pages):

  1. Nhấn nút "Tải Web Kèm Dữ Liệu" ở góc trên bên phải để lấy file index.html.
  2. Tạo 1 repository công khai trên GitHub.com và tải file index.html lên.
  3. Vào Settings → Pages → Branch: main và nhấn Save. Bạn sẽ có ngay địa chỉ https://ten-ban.github.io/ten-repo mở trực tiếp trên mọi máy tính, điện thoại!
